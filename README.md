# Python Contact Book - File Handling Project

A simple and useful Contact Book made with Python

## 📖 About
This project can Add, View, Search, and Delete contacts.
All contacts are saved in a file, so they don't get deleted when program closes.

## ✨ Features
- Add new contact
- View all contacts
- Search contact
- Delete contact
- File Handling used

## 🛠️ Tech Used
- Python
- File Handling
